# Deploy

Each workspace runs on its own VM. Pick a template, add your Claude and Codex logins, and connect the app.

## Hetzner

The cheapest way to run many agents. Template: Ubuntu, the gateway, the harness and a browser per agent.

## DigitalOcean

Same template as a Droplet.

## Google Cloud

Same template as a Compute Engine VM.

## Your own server

Any Ubuntu machine works. Run the provision script and connect the app over Tailscale.
