# Messaging

## One line

Run and manage 100 always-on agents in the cloud, from Mac and iOS.
The Codex app for AI employees. Open source.

## The leap

From personal assistants to AI employees: agents you can manage, watch and measure, doing jobs that make money.

## Value

1. **Always-on employees:** an OpenClaw-style harness on top of Claude Code and Codex; OpenClaw and Hermes support coming.
2. **Set up in a click:** a workspace and browser per employee, on your VMs.
3. **The Codex interface:** see every step, diff and browser; take over anytime.
4. **Real work:** browser use and integrations (ads, payments, email, CRM, socials) in the tools businesses run on.
5. **Scale:** 100 always-on employees from one app.

## Against Paperclip

Paperclip is a web dashboard for an org chart of agents. Overtime is a native, fast Mac and iOS app with the Claude Code interface, built around browser use and integrations that do real work.

## Problem

1. They stop when your laptop does.
2. The cloud is hard.
3. You can't see the work.
4. You can't step in.
5. Computer use doesn't scale.
6. Agents lose the thread.
7. They don't know when to ask.
8. Every agent has its own app.

## Solution

Move the agents to the cloud, keep the app: always-on agents on your VMs, a computer each, one app to watch, steer and take over all of them.

## Thesis

The solopreneurs and businesses that win will be the ones that figure out how to run tens to hundreds of always-on AI agents: doing productive work, coordinating with each other, and knowing when to hand off to a human. Today that is hard. Agents lose the thread, the tools to manage them and see their work are poor, and hosting many in the cloud is a pain.
